# Negócio

Plataforma para **geração e gestão de agentes de IA** voltados a negócios. A plataforma conecta dados externos e delega trabalho aos agentes de acordo com a demanda.

## Como funciona

1. **Conectores de dados externos** puxam informações de fontes variadas.
2. A partir desses dados, **experts** (agentes especialistas) executam tarefas sob demanda.
3. Cada persona de negócio opera dentro de sua área de responsabilidade.

## Personas

| Persona | Responsabilidade                                                              |
| ------- | ----------------------------------------------------------------------------- |
| **CEO** | Visualizar, analisar, trabalhar e implementar tarefas de negócio              |
| **CMO** | Visualizar, analisar, trabalhar e implementar tarefas de marketing            |
| **CTO** | Visualizar, analisar, trabalhar e implementar tarefas de processos de negócio |

## Principais conceitos

- **Agentes (experts):** automatizam tarefas dentro da sua especialidade.
- **Conectores de dados:** integram fontes externas que alimentam os agentes.
- **Demandas:** cada agente executa trabalho conforme um pedido/contexto recebido.
